ARRAY INDEXES 

unitCount vs. processUnits index 

as units get added, their unitCount value increases and is unique and constant, but
their array index in the unitCountList array can change as other units are deleted from the scene 

as unit objects get added to processUnits, their array index values increase but can decrease 
as other units get deleted from the scene 

so unitCount value and the processUnits array index value are not the same 

For an object currently on display in the scene, its array index in all three arrays
will be the same for its unitCount, unit ID, and unit object 
let unitCountList = []; // unitCount values of elements currently on display
let unitList = []; // ID's of unit objects currently on display
let processUnits = []; // processUnits holds an object for each unit currently on display 

Note that the unitCount value can be obtained from the unit ID but not vice versa 
let unitID = "cstr_42";
let unitCount = parseInt(unitID.split('_')[1]);  // gets 42
